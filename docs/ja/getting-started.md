# はじめに

[Phennec 利用ガイド](https://phennec.ai/setup) の要約です。

## 1. アカウントを作成する

1. Phennec コントロールパネルを開き、**Create an Account** をクリックします。
2. メールアドレスを入力します。メールのドメインに応じて、利用できるログイン方法が表示されます。
3. 届いたメールから登録を完了します。

## 2. セットアップウィザードに従う

初回ログイン時、ウィザードが次の4ステップを案内します。

1. 組織を作成する
2. プロジェクトを作成する
3. データソースを追加する
4. AI エージェントを接続する

途中で中断しても、別の端末からでも続きから再開できます。

## 3. データソースを追加する

プロジェクト画面で **Data Sources → Add Data Source** を開き、名前と説明を入力してサービスを選びます。名前と説明は埋め込み時の文脈として使われるため、データの出どころを具体的に書いてください。

## 4. AI エージェントを接続する

1. コントロールパネル左下のプロフィールアイコン → **MCP** を開き、使うクライアントを選びます。
2. クライアントの MCP 設定で Phennec の **Authenticate** をクリックします。
3. ブラウザで接続する組織を選び、**Allow** をクリックします。
4. クライアントで Phennec が **Connected** と表示されれば完了です。
