# Getting started

A short version of the [Phennec usage guide](https://phennec.ai/en/setup).

## 1. Create an account

1. Open the Phennec Control Panel and click **Create an Account**.
2. Enter your email address. Phennec shows the sign-in methods allowed for your email domain.
3. Complete registration from the email you receive.

## 2. Follow the setup wizard

On first sign-in a wizard guides you through four steps:

1. Create an organization
2. Create a project
3. Add a data source
4. Connect an AI agent

If you stop partway, the wizard resumes where your account left off, even on another device.

## 3. Add a data source

On the project screen, open **Data Sources → Add Data Source**, enter a name and a description, and pick the service. Both the name and the description are used as context during embedding, so say clearly where the data comes from.

See [data-sources.md](data-sources.md) for what each service needs.

## 4. Connect your AI agent

1. In the Control Panel, open the profile icon → **MCP** and pick your client.
2. In the client's MCP settings, click **Authenticate** for Phennec.
3. In the browser, choose the organization and click **Allow**.
4. Phennec shows as **Connected** in the client.
